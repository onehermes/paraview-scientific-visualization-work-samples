# Expected Outputs

## What A Successful Render Should Show

- arrows or glyphs aligned to the vector direction
- a readable difference between weak and strong vectors
- a color map that matches the selected interpretation
- optional streamlines that follow the rotational pattern
- a screenshot with a clear camera position and export settings

## What The Image Can Support

| Observation | What It Means | What It Does Not Mean |
| --- | --- | --- |
| Rotational arrow pattern | The vector components create circular motion around the z-axis | It does not prove the flow is physically realistic |
| Longer glyphs | Larger vector magnitude where the scale is documented | It does not mean the arrows are automatically more important |
| Streamlines | The field has a coherent direction structure | It does not confirm a real experiment or simulation |

## Practical Limitations

- glyph density can hide detail if the sampling is too aggressive
- color can be misleading if the legend and variable name are not explicit
- stream tracers depend on seed placement and integration settings
