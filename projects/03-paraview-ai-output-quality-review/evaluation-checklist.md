# Evaluation Checklist

- [ ] Does the answer name the dataset format?
- [ ] Does it identify the active scalar or vector array?
- [ ] Does it describe the filter order clearly?
- [ ] Does it explain why the chosen color map is appropriate?
- [ ] Does it include screenshot or export guidance?
- [ ] Does it state what the visualization can and cannot prove?
- [ ] Does it avoid vague language like "use whatever works best"?
- [ ] Does it stay reproducible without hidden assumptions?

## Pass Standard

An answer should only be considered usable if a second person can recreate the workflow without guessing the data type, array name, or filter sequence.
