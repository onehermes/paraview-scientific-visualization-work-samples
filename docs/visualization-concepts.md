# Visualization Concepts

This glossary is written for a beginner-to-intermediate reader who wants to understand ParaView work samples in a professional context.

| Term | Meaning |
| --- | --- |
| Scientific visualization | Turning scientific or simulation data into images that help people inspect structure, patterns, and change |
| Scalar field | A dataset where each sample point stores one value, such as temperature or pressure |
| Vector field | A dataset where each sample point stores direction and magnitude, such as velocity |
| Mesh/grid | The spatial structure that holds the data samples |
| Pipeline | The ordered chain of sources, filters, and display settings used to create a render |
| Filter | A processing step that changes, extracts, or visualizes data |
| Contour | A filter that draws lines or surfaces for selected scalar values |
| Slice | A filter that cuts through a dataset to expose a 2D section |
| Glyph | A filter that draws icons, often arrows, to represent vector direction and size |
| Streamline | A curve that follows a vector field over space |
| Color map | The mapping from data values to colors in the render |
| Screenshot/export | The step that saves the visualization as a shareable image file |

## Practical Reading Tip

A strong ParaView image is not just visually attractive. It should make it obvious what data is being shown, how it was processed, and what conclusions are safe to draw.
